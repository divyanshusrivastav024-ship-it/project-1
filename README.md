# Calculator Project in C

## Introduction
This is a simple calculator project developed using the C programming language as part of my 1st-semester college project. It performs basic mathematical operations.

## Objectives
- To understand the basics of C programming.
- To learn how to use variables and operators.
- To understand loops and switch statements.
- To perform basic mathematical calculations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exit option

## Technologies Used
- Programming Language: C
- Software: Visual Studio Code
- Compiler: GCC

## How to Run
1. Copy the source code into a file named `calculator.c`.
2. Open the terminal in Visual Studio Code.
3. Compile the program using:

   ```bash
   gcc calculator.c -o calculator
   ```

4. Run the program:

   ```bash
   .\calculator.exe
   ```

## Concepts Used
- Variables and data types
- `printf()` and `scanf()`
- `switch` statement
- `do-while` loop
- Arithmetic operators
- Conditional statements

## Conclusion
This project helped me understand the basic concepts of C programming and how to use them to create a simple calculator.
